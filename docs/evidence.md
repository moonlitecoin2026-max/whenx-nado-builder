# Evidence and claim boundaries

| Claim | Supporting material | What it does not prove |
|---|---|---|
| Live NADO public reads | Product terminal and dated public endpoint observations; `npm run markets` independently queries the official SDK endpoint | Live WHENX order execution or builder earnings |
| Existing Forecaster implementation | Dated engineering review of deployed code/state and original publication; public collection interface | Current automation uptime or an external security audit |
| Original publication complete | Independent publication record completed 7 November 2026: 252 archives, 75,010 objects, original checksums validated | A new download/re-audit of the entire collection by this demo |
| Verification implemented | Existing product verification tests and receipt evidence reviewed for this package | Universal support for every route, asset or future source |
| Public demo correctness | Reproducible TypeScript build, offline tests and separate actual public SDK query | Production receipt authentication or an XP award |
| Product screenshots | Actual dated disconnected interface captures | Personal balances, authenticated history or a live transaction |

Reproducible package checks and the dated public SDK observation are recorded in [validation.json](validation.json). The market-record count is the public API's returned dataset size, not a user, activity or growth metric.

Private implementation details, operational addresses and internal reports are intentionally excluded. This package is a curated demonstration, not a copy of the application or a substitute for a separate integration review.
