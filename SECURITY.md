# Security and disclosure scope

This repository is a curated demonstration project. It contains no production signer, account connector, private infrastructure configuration or financial execution service. Do not send secrets, seed phrases, personal information or operational configuration through issues or pull requests.

Examples use public NADO queries or explicitly synthetic fixtures. They do not authenticate real receipts, grant XP, place orders or claim fees. Registration and financial configuration are not inferred from SDK availability.

For a potential security issue, first request a private reporting channel through an approved WHENX project contact. Do not post exploit details or sensitive values publicly. No personal reporting address or bounty promise is invented here.

Third-party SDK packages may offer broader functionality than this showcase uses. The examples intentionally expose only their read-only subset and do not supply a wallet client. Review dependency updates before changing the committed lockfile.

A publication privacy review is not an independent smart-contract audit or a guarantee that the complete WHENX product is production-ready.
