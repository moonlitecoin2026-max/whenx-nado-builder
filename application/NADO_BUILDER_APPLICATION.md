## Overview

WHENX connects Forecaster NFT identity with wallet-linked, verifiable activity on Ink. Its aim is to make eligible activity easier to understand and connect it to persistent progression. Lifetime XP and NFT Protocol Power are separate concepts; no reward or return is guaranteed by ownership or by this application.

## NADO use case

We have built a dedicated public NADO market terminal with market selection, candles, depth and funding. The next proposed product path is user-authorized NADO order flow with correct registered-builder attribution, followed by independently verified activity and an approved eligibility policy.

The product includes activity-verification and duplicate-prevention implementation. It preserves provenance where multiple interfaces expose the same venue execution, rather than awarding twice. Production XP crediting/spending remain disabled, and the public verification service is not currently available. WHENX order execution and builder fees are not enabled.

## Technical evidence

The showcase contains actual product screenshots, an honest status matrix, architecture diagrams and isolated TypeScript examples. Those examples use official public SDK packages for market reads and offline builder appendix encoding. A synthetic example demonstrates cross-route idempotence and owner-binding checks without exporting production verification logic or issuing XP.

Forecaster contracts and original artwork commitments exist on Ink, with earlier private mint/reveal verification. Current reveal-automation availability is under review; this application does not claim uninterrupted production operations or a completed independent protocol security audit.

## Request

We would like NADO to evaluate WHENX for an official Builder ID and clarify:

1. Registration and eligibility requirements, and the correct submission channel.
2. Registered owner association and configuration review.
3. Permitted fee bounds, units and any attribution restrictions.
4. Current quote denomination, claiming/deposit costs and settlement conventions.
5. Recommended integration tests for order association, partial fills and historical activity.

We will use only a WHENX-assigned and approved Builder ID. We will not reuse another interface's attribution or represent a registration request as a partnership.

## Expected product benefits

For NADO: another Ink discovery/trading entry point and a progression-oriented interface. For users: convenient market access and inspectable eligible activity. For WHENX: genuine order attribution, a possible builder-fee source and a richer activity experience. We are not submitting projected volume, acquisition figures or revenue claims without evidence.

Financial activation, user order signatures and production XP require their own review. We request evaluation and integration guidance, not an assumption of acceptance.
